{{- if .Values.agent.enabled }}

The agent DaemonSet "{{ $fullname }}-agent" is enabled and serves the HTTP/JSON
wire API v1 on port {{ .Values.agent.port }} of every node. The hub talks to it
on each node's InternalIP with the shared agent-token. Check one agent:
  kubectl -n {{ .Release.Namespace }} port-forward ds/{{ $fullname }}-agent {{ .Values.agent.port }}:{{ .Values.agent.port }}
  curl -fsS http://localhost:{{ .Values.agent.port }}/healthz
{{- else }}

WARNING: agent.enabled=false. Without the node agents the live K8sProvider
reports every node as offline and cannot pull images. Enable agent.enabled=true
for a real deployment; use agent.mock=true for a socket-less smoke test.
{{- end }}
