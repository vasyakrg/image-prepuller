Hub:

  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}/

{{- if .Values.secret.create }}
Credentials (generated on install; retrieve them with):
  kubectl -n {{ .Release.Namespace }} get secret {{ $secretName }} -o jsonpath='{.data.auth-user}' | base64 -d
  kubectl -n {{ .Release.Namespace }} get secret {{ $secretName }} -o jsonpath='{.data.auth-pass}' | base64 -d
  kubectl -n {{ .Release.Namespace }} get secret {{ $secretName }} -o jsonpath='{.data.agent-token}' | base64 -d
{{- else }}
Credentials come from the existing secret "{{ $secretName }}".
{{- end }}

Health and metrics:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }} {{ .Values.hub.service.metricsPort }}:{{ .Values.hub.service.metricsPort }}
  curl -fsS http://localhost:{{ .Values.hub.service.httpPort }}/healthz
  curl -fsS http://localhost:{{ .Values.hub.service.httpPort }}/readyz
  curl -fsS http://localhost:{{ .Values.hub.service.metricsPort }}/metrics

{{- if .Values.hub.mock }}

WARNING: hub.mock=true -> the controller runs with -mock (in-memory data).
The default is the live K8sProvider; use -mock only for demos/UI work.
{{- end }}

{{- if .Values.agent.enabled }}

The agent DaemonSet "{{ $fullname }}-agent" is enabled and serves the HTTP/JSON
wire API v1 on port {{ .Values.agent.port }} of every node. The hub talks to it
on each node's InternalIP with the shared agent-token. Check one agent:
  kubectl -n {{ .Release.Namespace }} port-forward ds/{{ $fullname }}-agent {{ .Values.agent.port }}:{{ .Values.agent.port }}
  curl -fsS http://localhost:{{ .Values.agent.port }}/healthz
{{- else }}

WARNING: agent.enabled=false. Without the node agents the live K8sProvider
reports every node as offline and cannot pull images. Enable agent.enabled=true
for a real deployment; use agent.mock=true for a socket-less smoke test.
{{- end }}

{{- if .Values.spoke.enabled }}

Spoke "{{ .Values.spoke.clusterName }}" is enabled: service {{ $fullname }}-spoke
(HTTP {{ .Values.spoke.service.httpPort }}, metrics {{ .Values.spoke.service.metricsPort }}).
Point the hub at it with hub.remoteClusters, e.g.
  --set hub.remoteClusters="{{ .Values.spoke.clusterName }}=http://{{ $fullname }}-spoke.{{ .Release.Namespace }}.svc:{{ .Values.spoke.service.httpPort }}=<token>"
{{- end }}
