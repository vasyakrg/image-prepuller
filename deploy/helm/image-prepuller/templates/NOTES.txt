{{- if .Values.spoke.enabled }}

Spoke "{{ .Values.spoke.clusterName }}" is enabled: service {{ $fullname }}-spoke
(HTTP {{ .Values.spoke.service.httpPort }}, metrics {{ .Values.spoke.service.metricsPort }}).
{{- if .Values.spoke.hub.enabled }}

Outbound ("pull") mode: this spoke dials {{ .Values.spoke.hub.url }} every
{{ .Values.spoke.hub.syncInterval }} and holds that connection open. It needs no
ingress here and no inbound route from the hub; only egress from this cluster to
the hub host on 443. Register it on the hub: PREPULLER_MANAGED_CLUSTERS (the
"managed-clusters" Secret key, hub.managedClusters) must contain
  {{ .Values.spoke.clusterName }}=<this release's cluster-token>
Read the token here:
  kubectl -n {{ .Release.Namespace }} get secret {{ $secretName }} -o jsonpath='{.data.cluster-token}' | base64 -d
Keep spoke.replicaCount=1 in this mode: the hub command queue assumes a single
spoke replica.
{{- else }}

Direct mode: point the hub at it with hub.remoteClusters. The address below only
works when the hub runs in this same cluster/network; for a separate cluster use
spoke.hub.enabled (outbound) or publish this Service behind an ingress/LB, e.g.
  --set hub.remoteClusters="{{ .Values.spoke.clusterName }}=http://{{ $fullname }}-spoke.{{ .Release.Namespace }}.svc:{{ .Values.spoke.service.httpPort }}=<token>"
{{- end }}
{{- end }}
